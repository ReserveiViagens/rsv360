# Cadastrar unidade e entender os status

## Status de publicação (como aparece no portal)

Na prática você verá progressão do tipo: **rascunho** → **completo** → **em aprovação** → **publicado** (ou rejeitado). O painel `/anfitriao` resume **Em aprovação** e **Publicadas**.

## Passos

1. Entre no portal do anfitrião.  
   **Onde clicar:** rota `/anfitriao` (menu do parceiro após login).

2. Abra a lista de unidades.  
   **Onde clicar:** `/anfitriao/unidades` — coluna **Status**.

3. Cadastre a unidade.  
   🚧 **Formulário “Nova unidade” dedicado (`/anfitriao/unidades/nova`) não existe** na UI atual. Para a primeira unidade use **Importar planilha** (guia 07) ou edite uma unidade já listada se a operação já tiver criado o registro.

4. Complete os dados e salve como completo.  
   **Onde clicar:** `/anfitriao/unidades/[id]` → **Salvar (completo)**.

5. Envie para aprovação da equipe Reservei.  
   **Onde clicar:** na mesma tela, botão **Enviar para aprovação**.

## ⚠️ Quando falar com um humano

Se sua unidade ficou rejeitada ou presa em aprovação sem resposta, fale com o suporte/comercial — não tente “forçar” publicação fora do fluxo.
