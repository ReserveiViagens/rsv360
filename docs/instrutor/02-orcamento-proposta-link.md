# Orçamento → proposta e envio do link ao cliente

Na interface, o recurso se chama **link público** (não aparece o texto “Link Vivo”). É o mesmo conceito: o cliente abre a proposta pelo link.

## Passos

1. Partindo do orçamento, converta em proposta **ou** crie a proposta na lista.  
   **Onde clicar:** em `/orcamentos/[id]` → **Converter em proposta**; ou `/propostas` → **Novo** → `/propostas/nova`.

2. Abra a proposta no editor.  
   **Onde clicar:** lista `/propostas` → título da proposta → `/propostas/[id]`.

3. Revise o conteúdo e gere o link público.  
   **Onde clicar:** no editor, botão **Gerar link público**. Quando ativo, a UI mostra **Link público ativo**.

4. Copie o link e envie ao cliente (WhatsApp, e-mail, etc. — o envio em si é fora do Turismo).  
   **Onde clicar:** campo/área do link público na proposta; use **Preview** se quiser conferir antes.

5. Confira se o preview público responde.  
   **Onde clicar:** link no formato `/proposta/{id}` (site público), a partir do editor.

## ⚠️ Quando falar com um humano

Não altere totais “no feeling” só para fechar o cliente. Se o link não gerar ou o preview falhar, chame suporte técnico.
