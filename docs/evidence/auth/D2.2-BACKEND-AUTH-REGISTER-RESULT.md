# D2.2 — Backend `POST /api/v1/auth/register`

**Data:** 2026-06-22  
**Branch:** `feat/d2.2-backend-auth-register`

## Endpoint

`POST /api/v1/auth/register`

### Request

```json
{
  "name": "Nome",
  "email": "user@example.com",
  "password": "minimo-8-chars",
  "password_confirmation": "minimo-8-chars",
  "role": "user"
}
```

`role` opcional — apenas `user` ou `manager` (default `user`).

### Responses

| Status | Condição |
|--------|----------|
| 201 | Conta criada — `{ success, data: { id, name, email, role, ... } }` |
| 400 | Validação (campos ausentes, senha curta, confirmação) |
| 409 | E-mail já cadastrado |
| 501 | `DATABASE_URL` ausente |
| 503 | Erro de serviço |

Sem tokens no register (usuário faz login em seguida).
