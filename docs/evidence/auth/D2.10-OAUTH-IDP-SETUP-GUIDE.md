# D2.10 — Configurar Google e Facebook OAuth (passo 4)

## Modo mock (sem apps Google/Facebook) — use isto agora

Enquanto **não** tiver acesso aos consoles IdP, mantenha:

```env
OAUTH_DEV_MOCK=true
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
FACEBOOK_APP_ID=
FACEBOOK_APP_SECRET=
```

`OAUTH_BFF_SECRET` igual no **backend** e **site-publico** (já configurado no seu `.env`).

**Docker local** (stack `rsv360`):

```powershell
# Terminal 1 — webhook reset (opcional)
npm run staging:webhook

# Terminal 2 — recriar com .env
docker compose -p rsv360 up -d --force-recreate backend site-publico
```

**Dev sem Docker** (`apps/site-publico/.env`):

```env
OAUTH_DEV_MOCK=true
OAUTH_BFF_SECRET=<mesmo valor do backend>
BACKEND_INTERNAL_URL=http://localhost:3002
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

**Testar login social mock:** http://localhost:3000/login → botões Google/Facebook → usuário fictício `@oauth.local` + tokens na URL.

**Validar automatizado:**

```bash
npm run test:e2e:auth-oauth-mock   # 2 testes Google + Facebook
npm run test:e2e:auth-v1           # 9 testes API v1
```

Não defina `OAUTH_DEV_MOCK=false` até ter credenciais reais — o `validate:auth-env` em produção exige IdP ou bloqueia mock.

---

**Quando:** após staging local com `OAUTH_DEV_MOCK=true` validado.  
**Objetivo:** login social real em staging/produção (passo 4 abaixo).

## 1. Google Cloud Console

1. Acesse [Google Cloud Console](https://console.cloud.google.com/) → **APIs & Services** → **Credentials**.
2. **Create Credentials** → **OAuth client ID** → tipo **Web application**.
3. **Authorized redirect URIs** (exatos):

| Ambiente | URI |
|----------|-----|
| Staging | `https://staging.reserveiviagens.com.br/api/auth/google/callback` |
| Produção | `https://www.reserveiviagens.com.br/api/auth/google/callback` |
| Local (opcional) | `http://localhost:3000/api/auth/google/callback` |

4. Copie **Client ID** e **Client secret** para o `.env`:

```env
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_REDIRECT_URI=https://staging.reserveiviagens.com.br/api/auth/google/callback
```

## 2. Meta for Developers (Facebook)

1. Acesse [Meta for Developers](https://developers.facebook.com/) → seu app → **Facebook Login** → **Settings**.
2. **Valid OAuth Redirect URIs**:

| Ambiente | URI |
|----------|-----|
| Staging | `https://staging.reserveiviagens.com.br/api/auth/facebook/callback` |
| Produção | `https://www.reserveiviagens.com.br/api/auth/facebook/callback` |
| Local (opcional) | `http://localhost:3000/api/auth/facebook/callback` |

3. Copie **App ID** e **App Secret**:

```env
FACEBOOK_APP_ID=...
FACEBOOK_APP_SECRET=...
FACEBOOK_REDIRECT_URI=https://staging.reserveiviagens.com.br/api/auth/facebook/callback
```

## 3. Desativar mock

```env
OAUTH_DEV_MOCK=false
```

`OAUTH_BFF_SECRET` deve ser **idêntico** no backend e site-publico.

## 4. Validar e deploy

```bash
npm run validate:auth-env
docker compose -p rsv360-staging up -d --force-recreate backend site-publico
```

Smoke manual: `/login` → Google → redirect com `access_token`.

## 5. E2E automatizado (mock)

Enquanto não há credenciais IdP:

```bash
npm run test:e2e:auth-oauth-mock
```

Requer `OAUTH_DEV_MOCK=true` no site-publico (`:3000`) e backend saudável (`:3002`).
