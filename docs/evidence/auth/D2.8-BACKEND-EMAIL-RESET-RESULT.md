# D2.8 — E-mail reset produção (backend)

**Data:** 2026-06-22  
**Escopo:** adapter real para forgot-password v1 (`POST /api/v1/auth/forgot-password`)

## Entregue

| Item | Arquivo / config |
|------|------------------|
| Webhook HTTP | `PASSWORD_RESET_EMAIL_WEBHOOK` (+ `PASSWORD_RESET_EMAIL_WEBHOOK_SECRET` opcional) |
| SMTP / Amazon SES (via SMTP) | `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `SMTP_PORT`, `SMTP_SECURE` |
| Fallback dev | log JSON quando nenhum transport configurado |
| Link reset | `PASSWORD_RESET_BASE_URL` → `{base}/redefinir-senha?token=…` |
| Falha silenciosa | delivery error não quebra forgot-password (resposta genérica mantida) |

## Prioridade de transporte

1. `PASSWORD_RESET_EMAIL_WEBHOOK` (POST JSON)
2. SMTP quando `SMTP_HOST` + `SMTP_USER` + `SMTP_PASS`
3. Log em dev

## Payload webhook

```json
{
  "to": "user@example.com",
  "name": "Nome",
  "resetUrl": "https://www.reserveiviagens.com.br/redefinir-senha?token=…",
  "subject": "Recuperação de Senha - RSV 360°",
  "html": "…",
  "text": "…",
  "tokenPreview": "abcd…"
}
```

## Config produção (exemplo SES SMTP)

```env
PASSWORD_RESET_BASE_URL=https://www.reserveiviagens.com.br
SMTP_HOST=email-smtp.us-east-1.amazonaws.com
SMTP_PORT=587
SMTP_USER=<iam-smtp-user>
SMTP_PASS=<iam-smtp-password>
SMTP_FROM="Reservei Viagens <noreply@reserveiviagens.com.br>"
```
