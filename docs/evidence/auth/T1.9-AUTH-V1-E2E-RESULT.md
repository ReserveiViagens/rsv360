## Cenários #31

| # | Cenário | Assert principal |
|---|---------|------------------|
| 1 | Login válido → session 200 | `POST /api/v1/auth/login` + `GET /session` com Bearer |
| 2 | Credencial inválida → 401 | Senha incorreta |
| 3 | Refresh válido | `POST /refresh` retorna novo `access_token` |
| 4 | Logout revoga refresh | Após logout, `POST /refresh` → 401 |
| 5 | RBAC / enterpriseId | `session.user.enterpriseId` + `GET /tenant/context` com `X-Enterprise-Id` |
