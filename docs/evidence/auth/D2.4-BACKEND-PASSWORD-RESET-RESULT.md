## Comportamento

- **forgot-password:** sempre 200 genérico se e-mail válido; token SHA-256, TTL 60 min; invalida tokens anteriores do usuário
- **reset-password:** valida token, bcrypt cost 12, marca uso único, revoga refresh tokens
- **501** sem `DATABASE_URL`; **429** rate limit conforme spec

## Validação
