# T0.10 — Estabilização Docker guest + admin (pós-Next 16)

**Data:** 2026-06-12  
**Branch:** `fix/trilha-0-guest-admin-react-query-docker`  
**Escopo:** `apps/guest`, `apps/admin` — runtime Docker S2 (`rsv360`)

## Problema

Após Fase D (Next 16), containers `rsv360-guest` e `rsv360-admin` ficaram **unhealthy** com HTTP **500** em `:3006` e `:3004`.

**Erro nos logs:**

```
Failed to load external module @tanstack/react-query-a07b84a9a4b6bf2a
ERR_MODULE_NOT_FOUND — imported from [turbopack]_runtime.js
```

**Causa:** build de produção Next 16 com **Turbopack** (default) externaliza `@tanstack/react-query` com nome hash inexistente em `node_modules` no runtime. `@tanstack/react-query` **estava presente** em `node_modules/@tanstack/` — não era gap de cópia no Dockerfile.

## Correção aplicada

| Arquivo | Alteração |
|---------|-----------|
| `apps/guest/next.config.js` | `serverExternalPackages: ['@tanstack/react-query', '@tanstack/query-core']` |
| `apps/admin/next.config.js` | idem |
| `apps/guest/package.json` | `"build": "next build --webpack"` (prod Docker usa webpack, evita Turbopack SSR hash) |
| `apps/admin/package.json` | idem |

**Não alterado:** `docker/frontend/Dockerfile`, site-publico, turismo, backend, S1, auth/tenant/financeiro.

**Tentativas descartadas:**

- `serverExternalPackages` sozinho — build OK, runtime 500 persistiu (Turbopack prod).
- `transpilePackages` + `serverExternalPackages` — conflito Turbopack; falha adicional no build Alpine.
