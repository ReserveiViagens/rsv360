## 1. Contexto

Após TS6 Fase E (T0.14), o gate oficial de `site-publico` permanece **type-check pré-build** (sem `.next/types`). O build webpack passa com `typescript.ignoreBuildErrors: true`, mas o `tsconfig` inclui `.next/types/**/*.ts` — logo, após `next build`, `tsc --noEmit` falha com **1968 erros** (baseline documentado em T0.14).

Esta montanha trata **saneamento `.next/types`** antes de TW4 em `site-publico`, em PRs separadas e fatiadas.

**include (7 fontes + tipos Next):**

**Protocolo de gate recomendado (CI/local):**

1. `tsc --noEmit` **sem** pasta `.next` → gate operacional (mantém T0.14).
2. `next build --webpack` → gera `.next/types`.
3. `tsc --noEmit` **com** `.next/types` → gate desta montanha; medir delta por fase.

**Não fazer na fase 1:** ampliar `include`/`exclude`, TW4, alterar Dockerfile/backend.
