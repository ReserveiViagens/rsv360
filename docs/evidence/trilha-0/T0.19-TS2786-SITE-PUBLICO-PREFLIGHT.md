## 2. Causa raiz (TS2786)

Mensagem típica:

```text
'BarChart3' cannot be used as a JSX component.
Its type 'LucideIcon' is not a valid JSX element type.
Type 'import(".../node_modules/@types/react/index").ReactNode'
  is not assignable to type 'React.ReactNode'.
```

| Fator | site-publico | guest/admin (referência) |
|-------|--------------|--------------------------|
| `lucide-react` declarado | `^0.294.0` | `^0.542.0` |
| Resolvido lock | **0.294.0** | **0.542.x** |
| `@types/react` | `^19.2.0` | alinhado TS6 |
| React | **19.2.5** | **19.x** |

**Diagnóstico:** `lucide-react@0.294` pré-dates React 19 typings — gera conflito de `ReactNode` entre cópias de `@types/react`. Guest/admin já migraram Lucide na rodada TW4/TS6.
