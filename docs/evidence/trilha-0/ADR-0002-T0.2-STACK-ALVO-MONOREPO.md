# ADR-0002: Stack alvo do monorepo S2 (Trilha 0 — T0.2)

**Status:** Proposto — aguardando aprovação (`master_owner` / tech lead)  
**Data:** 2026-06-08  
**Decisores:** Equipe RSV360 (S2 monorepo)  
**Supersede:** ADR-0001 (2026-04-02 — split controlado React 18/19)  
**Evidência base:** [T0.1-REACT-NEXT-INVENTORY.md](./T0.1-REACT-NEXT-INVENTORY.md)  
**Referência visão:** PLANO-MESTRE-v3-CONSOLIDADO §2 (`docs/integracao-v3/sprint-0/` no repo integração)

---

## Contexto

Após G0–G4 **GO**, soak 72h e integração S1↔S2, a **Trilha 0** moderniza a stack do monorepo S2 sem fusão de código com o CRM legado (S1).

O inventário **T0.1** (2026-06-08) mapeou o estado real:

| Workspace | React | Next | Observação |
|-----------|-------|------|------------|
| `apps/site-publico` | **18.3.1** | 15.5.18 | Único app ainda em React 18 |
| `apps/admin`, `guest`, `turismo` | 19.2.5 | 15.5.18 | Alinhados entre si |
| Runtime host | Node **22.22.0** | — | Dockerfiles `node:22-alpine` |
| TypeScript | **5.9.3** resolvido | — | Declarações 5.0–5.9 por workspace |

Gaps registrados: GAP-T01 (React split), GAP-T02 (`@types/react` ^18 em apps React 19), GAP-T03 (Node 22 vs 24), GAP-T04 (Next 15 vs 16), GAP-T05 (hoist root `react ^19`).

O ADR-0001 autorizava manter `site-publico` em React 18 até “janela dedicada”. Com gates verdes e inventário fechado, **esta janela abre agora**, de forma **faseada e reversível**.

**Fora de escopo deste ADR:** S1 (CRM Express/React distinto), Tailwind 4, Express 5, TypeScript 6 — planejados após estabilização das fases A–D.

---

## Decisão

Adotar a **stack alvo do PLANO-MESTRE §2** no monorepo S2, executada em **cinco fases ordenadas**, com piloto **T0.3 em `apps/guest`**, gates obrigatórios entre fases e rollback documentado.

### Stack alvo (estado final Trilha 0)

| Camada | Atual (T0.1) | Alvo | Fase |
|--------|--------------|------|------|
| Node.js | 22.22.0 | **24 LTS** | C |
| Next.js | 15.5.18 | **16.2.x** | D |
| React / React DOM | 18.3.1 (site) / 19.2.5 | **19.2.x** unificado | B (+ tipos A) |
| TypeScript | 5.9.3 | **5.9.x** (curto prazo); **6.x** pós-Next 16 | A / E |
| npm (packageManager) | 10.9.7 | manter até fase C; revisar com Node 24 | C |
| Docker base | `node:22-alpine` | `node:24-alpine` | C |
| Tailwind | 3.x | 4.x | E (Trilha 0+) |
| Express (backend) | 4.x | 5.x | E (Trilha 0+) |

### Princípios

1. **Um major por PR** — não combinar React 19 + Next 16 + Node 24 no mesmo merge.
2. **Piloto antes de escala** — validar pipeline em app menor antes de `site-publico`.
3. **Gates verdes** — cada fase exige build, type-check, lint e smoke documentados.
4. **Hard stop temporada** — sem upgrades estruturais na semana de pico jul/2026 sem war room (PLANO-MESTRE §6.7).
5. **S1 intocado** — smoke S1 `:5000` permanece critério de integração; não alterar stack S1 nesta trilha.

## Fases de execução

### Fase A — T0.3 Piloto (`apps/guest`)

**Objetivo:** validar toolchain e tipos sem migrar React major.

| Ação | Detalhe |
|------|---------|
| Atualizar `@types/react` / `@types/react-dom` | ^19 alinhado ao React 19.2.5 |
| Atualizar `@types/node` | ^22 mínimo (prep Node 24) |
| Gates | `npm run build --workspace=apps/guest`, `type-check`, `lint`, smoke `:3006` |
| Evidência | `docs/evidence/trilha-0/logs/T0.3-GUEST-PILOT.tsv` |

**Não inclui:** bump Next 16 nem Node 24 (fases C/D).

### Fase B — Unificar React 19 em `site-publico`

**Objetivo:** fechar GAP-T01 (maior risco funcional do monorepo).

| Ação | Detalhe |
|------|---------|
| Subir `react` / `react-dom` | ^19.2.x + `@types/react` ^19 |
| Isolar hoist | `overrides` ou workspace lock até build verde |
| Gates | build site-publico, smoke `:3000`, API P0 round (8/8), E2E crítico se existir |
| Rollback | tag `pre-react19-site-publico` + imagem Docker anterior |

**Pré-requisito:** Fase A **GO**.

### Fase C — Node 24 LTS

**Objetivo:** fechar GAP-T03; alinhar host, CI e Docker.

| Ação | Detalhe |
|------|---------|
| `engines.node` (root) | `>=24.0.0 <25` |
| Dockerfiles | `node:24-alpine` (`docker/backend`, `docker/frontend`, `backend/Dockerfile`) |
| CI / dev | documentar `.nvmrc` ou ` volta pin` em `ENV-STANDARD` |
| Gates | `npm ci`, build all workspaces, `docker compose -p rsv360 build`, smoke stack |

**Pré-requisito:** Fases A + B **GO**.

### Fase D — Next.js 16.2.x

**Objetivo:** fechar GAP-T04; seguir [guia oficial de upgrade Next 15→16](https://nextjs.org/docs/app/building-your-application/upgrading).

| Ação | Detalhe |
|------|---------|
| Ordem sugerida | `guest` → `admin` → `turismo` → `site-publico` (menor → maior) |
| Gates por app | build, `next lint`, smoke da porta dev |
| Stack | React 19 já unificado (Fase B) |

**Pré-requisito:** Fase C **GO**.

### Fase E — PLANO-MESTRE residual (pós-Trilha 0 core)

TypeScript 6.x, Tailwind 4.x, Express 5.x — **ADR separado** após Fase D estável em produção/homolog.

## Critérios de aceite (gate por fase)

Cada fase só promove **GO** com:

| # | Critério |
|---|----------|
| G-A1 | PR dedicado + review |
| G-A2 | `npm run build` do escopo afetado — exit 0 |
| G-A3 | `npm run type-check` — exit 0 (workspace(s) tocados) |

| G-A6 | API P0 8/8 (`run-api-p0-round1.ps1`) após Fase B+ |
| G-A7 | Log TSV em `docs/evidence/trilha-0/logs/` |

## Consequências

### Positivas

- Stack única previsível; fim do split ADR-0001.
- Reduz risco de hoist/cache npm entre React 18 e 19.
- Alinha S2 ao PLANO-MESTRE antes de Fase 1 (identidade/tenant).
- Piloto guest limita blast radius.

### Negativas / riscos

| Risco | Mitigação |
|-------|-----------|
| Regressão `site-publico` (maior codebase) | Fase B isolada; rollback por tag/imagem |
| Breaking changes Next 16 | Upgrade app a app; codemods oficiais |
| Node 24 incompatibilidade nativa | Testar em Docker antes do host dev |
| Janela jul/2026 | Hard stop PLANO-MESTRE §6.7 |

---

## Alternativas consideradas

| Alternativa | Por que não |
|-------------|-------------|
| Big-bang (tudo num PR) | Viola gates G2/G4; rollback impossível |
| Manter ADR-0001 indefinidamente | GAP-T01 permanente; bloqueia PLANO-MESTRE |
| Piloto em `site-publico` primeiro | Maior superfície; guest já está em React 19 |
| Pular Node 24, ir direto Next 16 | Dupla variável runtime + framework |
