## 3. Estratégia proposta (implementação futura — **não executada**)

1. Bump **`typescript` → `^6.0.3`** mantendo em **`dependencies`** (salvo decisão HITL explícita de mover para `devDependencies`).
2. **Não** ampliar `include` / `exclude` do tsconfig.
3. Se TS5101 (`baseUrl`): avaliar `ignoreDeprecations: "6.0"` — site-publico **não** usa `baseUrl` hoje.
4. Gate type-check: rodar **`tsc` pré-build** (sem `.next/types`); registrar separadamente se pós-build falha (esperado pelo baseline).
5. Build: manter **`next build --webpack`**; não mudar para Turbopack sem evidência.
6. Docker: `docker compose -p rsv360 up -d --build site-publico` → `:3000` **200**, container **healthy**.
7. API P0: **8/8** obrigatório.
8. Correções mínimas **somente** em `apps/site-publico` se TS6 exigir; sem refactor visual/funcional.
