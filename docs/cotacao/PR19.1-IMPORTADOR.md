# PR 19.1 — Importador multi-formato (fatiado)

**Status:** ✅ Implementado

## Escopo

- `.xlsx` / `.csv` via SheetJS (determinístico)
- `.docx` via mammoth; `.pdf` via pdf-parse + OCR opcional (`IMPORT_OCR_ENABLED` + `tesseract.js`)
- `.md` → normalização LLM + validação **Zod** (`acomodacaoImportSchema`)
- Dry-run / preview com erros por linha (linha inválida não derruba o lote)
- Upsert idempotente por `codigo_externo` OU `(hotel_id + titulo)`
- Fila BullMQ `importacoes` (worker em `backend/server.js`)
- Template `.xlsx` modelo no Admin

## Rotas

- `POST /api/v1/acomodacoes/import/preview`
- `POST /api/v1/acomodacoes/import/commit` (`async=true` enfileira BullMQ)
- `GET /api/v1/acomodacoes/import/modelo.xlsx`
- BFF: `apps/site-publico/app/api/cotacao/acomodacoes/import`
- Admin UI: `apps/admin/pages/acomodacoes/import.tsx`
